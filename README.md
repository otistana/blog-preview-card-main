## My process
- I worked through this project step by step and coded most of it myself. When I wasn't sure where to start or got stuck on something, I asked ChatGPT questions and had it explain things to me as I went. It was basically like having a teacher sitting next to me while I worked.

I started off pretty strong with the CSS, but I eventually got stuck on the sizing and positioning of my card and avatar. I used my AI coding agent to help me figure out what was causing the problem and, more importantly, to explain why the changes it suggested worked.

I tried not to just copy an answer and move on. I wanted to understand what I was changing and why. After finishing the project, I tested it at different screen sizes in Safari to make sure the layout worked properly on both desktop and mobile.

### What I learned

This project helped me become more comfortable with building a webpage from scratch using HTML and CSS. I practiced structuring the page with semantic HTML and using CSS Grid and Flexbox for different parts of the layout.
I started the CSS on my own and was able to make good progress, but I ran into some difficulty with the sizing and positioning of the card and avatar. Instead of only changing the code until it worked, I used AI to help troubleshoot the issue and explain why the CSS was affecting the layout the way it was.
One of the biggest things I took away from this project was learning to look at my CSS and understand how different layout properties affect the position and size of elements. I also practiced testing the finished project at different screen sizes to make sure the layout remained responsive.

### AI Collaboration 
I used ChatGPT and an AI coding agent as learning and troubleshooting tools throughout this project.
I used ChatGPT to walk through the development process and help me understand concepts as I worked. I primarily wrote the code myself, but I used AI when I needed guidance or clarification.
When I had difficulty with the sizing and positioning of the card and avatar, I used my AI agent to help troubleshoot the CSS. I also asked it to explain why the changes worked instead of simply applying the suggested solution.
Using AI this way helped me solve problems while also learning more about the CSS concepts behind the solution. It was most useful when I treated the AI as a teaching and debugging tool rather than simply asking it to write the project for me.
